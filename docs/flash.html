Flash CYD Dashboard

Install the firmware onto your Cheap Yellow Display straight from the browser — no toolchain needed.

  1. Connect the board over USB.
  2. Click Install and pick the serial port.
  3. The chip (ESP32 / ESP32-S3) is detected automatically — the matching image is flashed.
Your browser doesn't support Web Serial. Serial access not allowed — use HTTPS and grant permission.

Flashes bootloader, partitions, app and filesystem (web fallback + icons).

Chromium browsers only (Chrome, Edge, Opera) — Web Serial isn't available in Firefox or Safari. On Windows you may need a USB-UART driver: CH340 or CP2102.

Source & releases: github.com/ange007/CYD-Dashboard
